# Сквозной ИИ-конвейер коммерческой аналитики и кредитного скоринга

## 🏢 Бизнес-контекст проекта
Проект представляет собой автономную экосистему автоматизации сбора данных (ETL/ELPipeline), коммерческой сегментации клиентов и развёртывания трёх независимых моделей машинного обучения (Machine Learning) для задач ритейла и финтех-сектора.

## 🛠️ Архитектура и структура репозитория
*   📂 **`scripts/`** — Модули автоматизации и машинного обучения на Python (Pandas, NumPy, Scikit-Learn).
*   📂 **`data/`** — Результаты работы ИИ-скриптов (чистые датасеты) и интерактивный многостраничный дашборд Power BI.

---

## 🧠 Ключевые модули системы и ИИ-модели

### 1. Автоматизация ETL/ELT и клининг данных
*   **Логика:** Автоматическая очистка строковых аномалий, нормализация кривых форматов дат и склеивание таблиц продаж со справочниками CRM. Рутинный труд аналитика полностью автоматизирован.

### 2. Коммерческий RFM-анализ лояльности базы
*   **Логика:** Математическое квантильное деление клиентов по давности, частоте и суммам покупок. База автоматически сегментирована на VIP, Лояльных и Уходящих для точечного маркетинга.

### 3. Прогнозирование выручки (Модель Регрессии)
*   **ИИ-алгоритм:** Линейная регрессия (`LinearRegression`).
*   **Бизнес-суть:** На основе метода наименьших квадратов (МНК) рассчитан коэффициент ежемесячного роста тренда и построен точный математический прогноз выручки на 3 месяца вперёд для планирования бюджетов.

### 4. Кредитный скоринг клиентов (Модель Классификации)
*   **ИИ-алгоритм:** Логистическая регрессия (`LogisticRegression`).
*   **Бизнес-суть:** Модель обучается на анкетах прошлых заёмщиков и выстраивает границу решения. ИИ автоматически одобряет надёжные заявки (класс 1) и мгновенно блокирует рискованные анкеты с низким рейтингом (класс 0).

### 5. Автоматическая группировка базы (Модель Кластеризации)
*   **ИИ-алгоритм:** Метод К-средних (`KMeans`, обучение без учителя).
*   **Бизнес-суть:** Робот самостоятельно нанёс покупателей на карту признаков и разделил базу на две чёткие коммерческие группы: молодёжь с небольшим чеком и зрелые клиенты с высокими тратами.

---

## 📊 Визуализация и BI-слой
Все результаты расчетов ИИ-моделей импортированы в интерактивный 5-страничный аналитический дашборд **Power BI**, формируя для руководства законченную экосистему сквозной коммерческой аналитики.
